# Conductor - Morning Brief

Part of the **MC Conductor** bundle. The Morning Brief is the opening ritual: it prepares a leader for the day without turning the day into a source audit.

**Frame:** What does today require from me, and what must not get lost?

## Conductor Profile

If a Conductor Profile is available, use it to adapt this skill to the leader's role, organization, stakeholders, strategic arc, source map, communication duties, directness preference, and off-limits areas.

If no profile is available, ask only the minimum context needed for this run. Do not force the full onboarding interview unless the user is intentionally setting up Conductor. See `docs/onboarding.md` for the shared setup flow.

## What this skill does

Use this at the start of a workday. Bring your own sources: calendar, meeting notes, board packets, investor updates, CRM notes, inbox threads, direct-report dashboards, project trackers, journal notes, assistant notes, prior Conductor outputs, or anything else that gives useful signal.

The brief should be a 3-4 minute read. It should orient the leader, not flood them.

## Evidence protocol

Sources are inputs, not the visible structure. Do not write a source-by-source audit in the body.

At the same time, do not pretend you saw evidence you were not given. Track the source state while you work:

- **Used:** the source was provided and informed the brief.
- **Provided, no signal:** the source was available but did not change the read.
- **Missing:** the source would materially improve confidence but was not provided.

End with a short `Sources used:` line. If an important source is missing, name the gap plainly. Never invent a technical reason or imply a source was checked when it was not.

## Minimum input

If the leader provides no material, ask for:

1. Today's calendar.
2. The top 3 open commitments or decisions.
3. Any prior weekly or monthly Conductor output.

If they provide only partial material, proceed and label the confidence limits.

## Read the day in this order

### 1. Day Shape

Assess the architecture of the day:

- Rhythm: back-to-back, spacious, fragmented, travel-heavy, meeting-heavy, decision-heavy.
- Energy demands: which moments require presence, judgment, restraint, or conviction.
- Meeting mix: customers, board, investors, direct reports, internal ops, external partners, public voice, deep work.
- Protected time: whether thinking time is real or just leftover.
- Strategic alignment: whether today's calendar serves the leader's current priorities.
- Drift risk: what the day is likely to crowd out.

Do not summarize every meeting. Name the shape.

### 2. Strategic Alignment

Look for the most recent Sunday Reflection, Friday Pattern Read, Monthly Review, Quarterly Positioning, strategic plan, CEO priorities, board goals, or Coaching Diagnostic Brief.

If a current priority exists, compare it to today's calendar:

- If aligned, name the alignment.
- If misaligned, name the drift.
- If no strategic anchor was provided, do not stub the sentence. Simply omit it and note the missing source in `Sources used:`.

### 3. Meeting Readiness

Identify only meaningful meetings. Routine holds, admin blocks, and low-stakes check-ins belong in Day Shape unless they reveal a pattern.

For each meaningful meeting, write a short readiness block:

- Who is in the room.
- What is actually at stake.
- What happened last time, or what context carries forward.
- What the leader owes them or what they owe the leader.
- The posture to bring: listening, deciding, pushing, clarifying, slowing down, closing.
- One signal to watch that will reveal whether the meeting went well.

For high-stakes meetings, add a **5-minute pre-read**: the one document, thread, note, or question to review immediately before the meeting. Do not create a pre-read block for routine meetings.

### 4. Strategic Threads

Include this only when there is a genuine cross-meeting or longer-running pattern. Keep it to one short paragraph.

Examples:

- Multiple meetings all test the same decision.
- The same stakeholder concern appears in different rooms.
- A recurring leadership pattern from Friday or Sunday is likely to surface today.
- A long-running relationship or board dynamic is entering today's conversations.

Skip this section if there is no real thread. Forced connections are worse than silence.

### 5. Do Not Lose

Surface 1-3 unscheduled gravity items. These are commitments, decisions, relationships, or strategic questions that are not on today's calendar but still matter.

Use this test: if today's calendar were different, would this still matter to surface? If yes, it belongs here. If no, fold it into Meeting Readiness.

Prioritize:

- Commitments from recent meeting notes or sent messages.
- Priorities named in the most recent Sunday Reflection.
- Patterns named in the most recent Friday Pattern Read that remain live.
- Decisions deferred more than once.
- Relationship threads at risk of going quiet.
- Near-term deadlines without protected time.

This is not a full task manager. Include only what will compound if ignored.

### 6. Grounding Question

End with one grounded intention-setting question. It should help the leader choose how to show up today.

Strong examples:

- "Which meeting today needs your clearest no?"
- "Where are you most likely to confuse responsiveness with leadership?"
- "What would make today strategically useful, not just full?"
- "Who needs you fully present today, not partially available?"

## Output format

```
## Morning Brief - [Date]

### Day Shape
[One tight paragraph. Name the architecture of the day and the strategic alignment or drift if evidence supports it.]

### Meeting Readiness
[One short block per meaningful meeting, chronological order. Include 5-minute pre-read only for high-stakes meetings.]

### Strategic Threads
[Optional. One short paragraph. Omit if no genuine thread surfaced.]

### Do Not Lose
[Optional. 1-3 unscheduled gravity items. Omit if nothing qualifies.]

### Question
*[One grounded intention-setting question.]*

Sources used: [Used sources; missing sources that materially limit confidence.]
```

## Quality bar

- Chief-of-staff judgment, not calendar-assistant summary.
- Executive orientation, not source audit.
- Short paragraphs over bullet sprawl.
- Every sentence should earn its place.
- No generic "busy day ahead" filler.
- If the leader is overcommitted, say so.
- If the day does not serve the stated strategy, name the drift.
- If source coverage is thin, say so without over-apologizing.

## Where this fits in the Conductor rhythm

The Morning Brief opens the loop. The **Evening Hot Take** closes the day by checking what actually happened. The **Friday Pattern Read** sees which daily patterns repeated. The **Sunday Reflection** turns those patterns into meaning and priority. The **Monthly Review** names what is becoming true. The **Quarterly Positioning** asks what should be set up next.
